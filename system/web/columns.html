Three columns divide the row

Performance

Each of these three sections asks for the whole width. A row that could not shrink a percentage gave each of them all of it and ran three times off the right edge.

Reliability

The container is a column with no stated height, so the wrapper's flex:1 is about height and must not be read as a width of zero.

Productivity

And the whole page stays inside the window, which is the only thing a reader notices.

CAPPED: width 100% but never past 420px.
